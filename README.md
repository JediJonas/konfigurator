# Konfiguratorn

Bygg ett pepparkakshus i 3D och skriv ut ritningen i skala 1:1. Allt körs i webbläsaren.

```sh
npm install
npm run dev      # utvecklingsserver
npm test         # enhetstester (Vitest)
npm run e2e      # flöden i webbläsaren (Playwright)
npm run build    # statisk webbplats i dist/
```

Kravbilden står i [docs/SPEC.md](docs/SPEC.md) och principerna för koden i [CLAUDE.md](CLAUDE.md).

Mätruta för mobilen: lägg till `?matt` i adressen.
